# Barabari Collective

Barabari Collective builds and maintains technology systems across education and software services.

We operate through focused verticals that deliver real, usable systems — not demos or experiments.

---

## Our Verticals

### Tech Collective
A service-focused engineering vertical delivering software solutions, tooling, and technical implementations.

This vertical handles:
- Client-facing development work
- Internal tooling and infrastructure
- Engineering support across Barabari initiatives

---

### EdTech System
A product-focused vertical building tools for facilitators and students.

This vertical focuses on:
- Education platforms and internal tools
- Facilitator-facing systems
- Student-facing learning infrastructure

---

### Academic Projects
A structured space for curriculum-aligned academic repositories and reference implementations.

This vertical supports:
- Academic assignments
- Structured project work

---
